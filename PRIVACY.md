# Flashlight Alert プライバシーポリシー

最終更新日: 2026年8月7日

Flashlight Alert（以下「本アプリ」）は、ライトの点灯状態と端末の操作状態を端末上で確認し、ライトの消し忘れを通知するAndroidアプリです。

## 収集・共有する情報

本アプリは、個人情報、端末情報、利用状況、位置情報、カメラ画像その他の利用者データを収集、保存、外部送信または第三者へ共有しません。外部サーバーとの通信機能、広告、分析SDKはありません。

## 権限の利用目的

- カメラ権限: ライトの点灯・消灯を切り替えるために使用します。画像や映像の撮影には使用しません。
- 通知権限: 監視中であること、およびライトが点灯したままであることを通知するために使用します。
- Foreground ServiceおよびWakeLock: 画面消灯中の監視と、設定時間経過後の警告判定を端末内で継続するために使用します。

言語と警告時間の設定は端末内にのみ保存されます。本アプリをアンインストールすると、Androidの通常の仕組みにより削除されます。

## 配布元

正規の配布物は、開発者が管理する[GitHub Releases](https://github.com/nao-dev-space/flashlight-alert-releases/releases)から提供します。Google Play外からのインストールに伴うAndroidの警告内容を確認したうえで利用してください。

## 変更

# Flashlight Alert Privacy Policy

Last updated: August 7, 2026

Flashlight Alert checks the flashlight and device-interactive state locally on the device and warns the user when the flashlight may have been left on.

## Data collection and sharing

The app does not collect, store, transmit, or share personal information, device information, usage data, location data, camera images, or any other user data. It contains no external server communication, advertising, or analytics SDKs.

## Permissions

- Camera: Used only to switch the flashlight on and off. The app does not capture images or video.
- Notifications: Used to show the ongoing monitoring status and flashlight warnings.
- Foreground service and wake lock: Used to continue on-device monitoring while the screen is off and to evaluate the configured alert delay.

Language and alert-delay preferences are stored only on the device and are removed through Android's normal uninstall process.

## Distribution

Official builds are provided from the developer-managed [GitHub Releases](https://github.com/nao-dev-space/flashlight-alert-releases/releases). Users should review Android's warning before installing an app from outside Google Play.

## Changes

If this policy changes, the last-updated date in this file will be updated and the revision will be published on GitHub.
